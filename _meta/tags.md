# Controlled Tag Vocabulary

Use lowercase nested tags. A normal Learning Post uses one domain, one format, two to five topics, and optionally one level.

## Domains

- `domain/software-engineering`
- `domain/cloud`
- `domain/devops`
- `domain/infrastructure`
- `domain/networking`
- `domain/databases`
- `domain/programming-languages`
- `domain/algorithms`
- `domain/data-structures`
- `domain/data-science`

## Formats

These are facets of the shared Learning Post model, not separate content types.

- `format/concept`
- `format/deep-dive`
- `format/implementation`
- `format/tutorial`
- `format/troubleshooting`
- `format/comparison`
- `format/retrospective`
